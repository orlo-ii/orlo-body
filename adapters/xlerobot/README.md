# XLeRobot Adapter

Translates between the XLeRobot dual-arm mobile robot and the orlo-body protocol.

## Status: Planned

XLeRobot: https://github.com/Vector-Wangel/XLeRobot
- Dual-arm mobile household robot ($660)
- Built on LeRobot / SO-100 / Lekiwi
- Keyboard/Xbox/Switch/VR control
- MuJoCo simulation available

## Capabilities
- Movement (differential wheel base)
- Manipulation (dual 6-DOF arms with grippers)
- Perception (head-mounted RGB/RGBD camera)

## Dependencies
- Python 3.10+
- XLeRobot SDK / lerobot
- websockets
