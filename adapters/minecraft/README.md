# Minecraft Adapter

Translates between Minecraft (via mineflayer) and the orlo-body protocol.

## Status: In Progress

Port from `orlo-ii/dropbox/minecraft-orlo/` — refactor perception.js and
actions.js to speak the orlo-body protocol over WebSocket instead of
shelling out to the Hermes CLI.

## Dependencies
- Node.js 20+
- mineflayer, mineflayer-pathfinder, mineflayer-collectblock
